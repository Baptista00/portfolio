Sou estudante de Sistemas de Informação na UNIFEBE. Tenho projetos web em JavaScript, HTML e CSS, como a Lista de Compras e o AluGames, e uso Python e SQL nos estudos. Na faculdade, aprendo Java nas aulas de programação. Também estou aprendendo React Native e TypeScript.

Projeto em destaque

SubTrack

O SubTrack é um aplicativo mobile desenvolvido para organizar assinaturas recorrentes, permitindo acompanhar gastos mensais e anuais, controlar renovações e receber lembretes antes das cobranças.

O projeto foi desenvolvido utilizando React Native (Expo), Supabase e PostgreSQL, contando com autenticação por e-mail, confirmação de cadastro, recuperação de senha, dashboard financeiro, notificações locais e persistência em nuvem.
