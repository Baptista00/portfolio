Projeto em destaque

SubTrack

Em desenvolvimento

O SubTrack é um aplicativo mobile em desenvolvimento para concentrar a organização de assinaturas recorrentes, como Netflix, Spotify, ChatGPT, Google One, academia e outros serviços. A proposta é permitir uma visão clara dos gastos mensais e anuais, além de lembretes sobre renovações.

O projeto está sendo desenvolvido como uma oportunidade de aplicar novos conhecimentos em uma solução mais completa, desde a experiência mobile até autenticação e persistência de dados.

  • React Native
  • Expo
  • JavaScript
  • Supabase
  • PostgreSQL
  • Supabase Auth
  • Git/GitHub

Próxima evolução: futuramente, o projeto prevê o uso de Inteligência Artificial para gerar insights sobre os gastos, identificar padrões e apoiar o controle de despesas recorrentes.

Escopo planejado do MVP

  • Cadastro, login e recuperação de senha
  • Adicionar, editar e excluir assinaturas
  • Dashboard de gastos mensais e anuais
  • Notificações de renovação
  • Perfil e configurações
